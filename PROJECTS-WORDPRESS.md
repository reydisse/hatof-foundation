# Managing Project Funder(s) in WordPress

Project funders are supported by version 1.5.0 or newer of the HATOF WordPress plugin.

1. In WordPress, open **Projects → All Projects**.
2. Edit a project.
3. Find the **Project Funder(s)** panel.
4. Enter one or several organizations, separated by commas or new lines.
5. Update the project.

The public Project Information panel displays the saved value under **Funder(s)**. Existing projects show **Not specified** until this field is completed.
