# Managing Staff in WordPress

Staff management and the one-click migration are included in version 1.4.0 or newer of the HATOF WordPress plugin.

## Import the current staff

1. Install or update the HATOF Events plugin.
2. In WordPress, open **Staff → Import Current Staff**.
3. Click **Import Current Staff** once.
4. Review the imported profiles under **Staff → All Staff**.

The importer copies the 10 current profiles, biographies, categories, photographs, and display order from hatof.org. It records each imported profile and skips duplicates if it is run again.

## Edit staff later

- The WordPress title is the staff member's displayed name.
- The main editor contains the biography.
- The Featured Image is the displayed photograph.
- Staff Categories control the section in which the person appears.
- The Order field controls the order of people within the page.
- Unpublish a profile to remove it from the public staff page without deleting it.
