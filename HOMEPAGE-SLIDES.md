# Managing Homepage Slides

Homepage slide backgrounds are managed by version 1.3.0 or newer of the HATOF WordPress plugin in `wordpress-plugin/hatof-events`. WordPress changes only the image or video; the existing homepage text and buttons remain untouched.

## Add a slide

1. In WordPress, open **Homepage Slides → Add New Homepage Slide**.
2. Enter an internal title such as **Slide 1**. This title is not displayed on the homepage.
3. Complete the media fields in the **Slide Details** panel.
4. For an image background, select **Image** and set the **Featured Image**.
5. For a video background, select **Video**, choose an uploaded MP4, and also set a Featured Image as the video poster/fallback.
6. Set the Order value under **Page Attributes**. The lowest value controls the first existing homepage slide, the next controls the second, and so on.
7. Publish the slide.

Draft slides are not shown. If no slides are published or WordPress is unavailable, the homepage retains its original built-in slides.
